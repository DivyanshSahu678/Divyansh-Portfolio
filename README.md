## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/DivyanshSahu678/Divyansh-Portfolio.git
```

### Navigate to the Project

```bash
cd Divyansh-Portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
